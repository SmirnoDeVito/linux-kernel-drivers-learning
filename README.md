# Linux Kernel Drivers: Learning Journey / Учебные драйверы Linux

[English version below](#english-version)

## 🇷🇺 О проекте (Russian)

Этот репозиторий создан в учебных целях для изучения разработки драйверов устройств под операционную систему Linux. 

Здесь я шаг за шагом прохожу материал из книги *«Linux Kernel Programming Part 2»* и практикую написание загружаемых модулей ядра (LKM), в частности символьных драйверов класса `misc`.

### ⚠️ Важное предупреждение (Disclaimer)
**Код в этом репозитории предназначен ИСКЛЮЧИТЕЛЬНО для обучения.**
*   Не запускайте эти драйверы на реальной (рабочей) системе. Ошибка в коде ядра может привести к падению системы (Kernel Panic) или повреждению данных.
*   Все тесты проводились в изолированной виртуальной машине (VirtualBox) с Ubuntu.
*   Некоторые учебные драйверы намеренно содержат уязвимости (для демонстрации проблем безопасности), поэтому не используйте их в продакшене.

### 🛠️ Что здесь будет
*   `ch1_misc_driver/` — простой драйвер символьного устройства (класс `misc`), с функциями `open`, `read`, `write`, `release`.
*   `ch2_.../` — примеры взаимодействия «пользователь-ядро» (sysfs, debugfs, ioctl).
*   И другие эксперименты по мере продвижения по книге.
